## Objectives

The main objectives of this project are to:

* Identify and handle missing values
* Detect and correct inconsistent data
* Standardize text and categorical information
* Identify and remove duplicate records
* Restructure and transform existing columns
* Combine relevant information into meaningful fields
* Apply appropriate number and date formatting
* Use conditional formatting to improve data visualization
* Prepare a cleaner and more analysis-ready dataset


## Dataset

The dataset contains product-related information, including:

* Product ID
* Product Name
* Brand Name
* Quantity
* Category
* Price

The dataset was explored and prepared using Microsoft Excel.

The following data preparation activities were performed:

#Missing Value Handling

#Duplicate Removal
    Checked the dataset for duplicate records and removed duplicate rows where applicable.

    Restructured the Product ID information and created meaningful fields from the available data. Relevant product information was also combined to create a more useful Product Brand field.

#Formatting
Applied appropriate formatting to:
   * Price values
